## 发现的 Bug

### Bug 1: 指标/维度/模型"创建"按钮不生效（严重）

**现象**: 点击表单中的"创建"按钮后，表单数据不变，列表不刷新，无错误提示。

**验证**: 通过 API 直接调用 `POST /api/datasources/:dsId/metrics`、`POST /api/datasources/:dsId/dimensions`、`POST /api/datasources/:dsId/models` 均可正常创建，确认问题在前端表单提交逻辑。

**影响范围**: 指标创建、维度创建、模型创建

**可能原因**: 表单 `onSubmit` 事件未正确绑定，或按钮点击事件未触发提交逻辑。

---

### Bug 2: 点击指标/模型项无法进入编辑模式（严重）

**现象**: 点击列表中的指标或模型项后，右侧面板仍显示"新增"表单，不会切换到"编辑"模式。维度的点击编辑功能正常，说明组件间逻辑不一致。

**影响范围**: 指标编辑、模型编辑

**对比**: 维度组件点击后可正常进入编辑模式（截图 12），说明该功能在维度组件中已正确实现，指标和模型组件可能缺失了相同的事件处理。

---

### Bug 3: 指标"测试"按钮无可见反馈（轻微）

**现象**: 点击"测试"按钮后，页面没有任何结果展示（无 toast 通知、无弹窗、无内联结果区域）。

**影响范围**: 指标测试功能

**可能原因**: 测试结果可能以 toast 显示但自动消失太快，或结果未正确渲染到 DOM 中。

## API 层验证

通过 API 直接测试，以下功能均正常工作：

|---|---|---|

| `/api/datasources/:dsId/models` | POST | ✅ 创建成功 |

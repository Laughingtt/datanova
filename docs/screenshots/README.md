# Screenshots

This directory holds PNG screenshots used in the README and docs/.

> **Maintenance:** screenshots are kept up to date manually. When the UI
> changes meaningfully, re-capture with the helper script below.

## Required screenshots

| File | Captures | Approximate dimensions |
|---|---|---|
| `dashboard.png` | Dashboard page with stats tiles and recent activity | 1440×900 |
| `chat-streaming.png` | Chat with a streaming response, showing thinking + tool calls + SQL + table + summary | 1440×900 |
| `metrics-list.png` | Metrics management page (list + side detail) | 1440×900 |
| `query-skill-form.png` | Query-skill edit form | 1440×900 |
| `insights.png` | Insights BI dashboard | 1440×900 |
| `agent-traces.png` | Agent-traces page with one trace expanded (decision chain) | 1440×900 |

## How to re-capture

```bash
# 1. Make sure the demo dataset is loaded and dev servers are running.
./docs/demo-data/load.sh
npm run dev:server   # in one terminal
npm run dev:web      # in another

# 2. Run the capture script (uses Playwright, headless).
./scripts/capture-screenshots.mjs

# Screenshots will be written into this directory, overwriting old ones.
```

The capture script lives at [`scripts/capture-screenshots.mjs`](../../scripts/capture-screenshots.mjs)
and is generated by the maintainer team. PRs that significantly change the
UI **must** include updated screenshots.
